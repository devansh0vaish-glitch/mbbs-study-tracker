# MBBS Study Tracker

Free static web app for GitHub Pages.

## Files
- `index.html` — app shell
- `app.js` — features and local storage
- `style.css` — iPad-friendly interface
- `syllabus.js` — embedded 19-subject syllabus

## GitHub Pages
Create a GitHub repository, upload all four files to the repository root, then enable:
Settings → Pages → Deploy from branch → main → / (root)

The app stores study progress in the browser using localStorage.
